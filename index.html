How to make a token
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → your PokeSniper repo.
  3. Repository permissions: Actions, Contents and Workflows → Read and write.
  4. Generate, copy, paste above. GitHub only shows it once.
